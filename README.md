# P. Harish Sarathy — Portfolio

A static, dependency-free personal portfolio site. Plain HTML, CSS and JavaScript — no build step.

## Structure

```
index.html
css/style.css
js/script.js
assets/img/harish.jpg
favicon.svg
robots.txt
sitemap.xml
```

## Deploy to GitHub Pages

1. Create a repository (e.g. `phsharish.github.io`, or any name for a project page).
2. Push these files to the repository root (or to `/docs` if you prefer, then set that as the source).
3. In the repo, go to **Settings → Pages**, set the source branch (usually `main`) and folder (`/` or `/docs`), and save.
4. Your site will be live at `https://<your-username>.github.io/` (or `https://<your-username>.github.io/<repo-name>/` for a project page).

## Before going live — update these placeholders

- `index.html` and `sitemap.xml` use `https://phsharish.github.io/` as a placeholder canonical URL. Update both if your final URL is different (especially if you deploy as a project page with a `/repo-name/` path).
- The `og:image` path assumes the site is served from the domain root; adjust if deployed under a subpath.

## A note on the content

This site publishes a real name, school, photo, email and social links publicly. If you'd rather keep the school name or email address more private before this goes live, those are easy to remove or replace — just say the word.
